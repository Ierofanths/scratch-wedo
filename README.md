# WeDo 2.0 για Scratch (TurboWarp)

Επέκταση για τον editor TurboWarp (συμβατό με Scratch 3) που συνδέεται με το WeDo 2.0 απευθείας μέσω Web Bluetooth.

- `index.html` – αρχική σελίδα με κουμπιά, οδηγίες και QR codes (τα links φτιάχνονται αυτόματα)
- `wedo2-gr.js` – ελληνικά blocks
- `wedo2-en.js` – αγγλικά blocks

Λειτουργεί σε Chrome / Edge (Windows, macOS, ChromeOS, Android).
